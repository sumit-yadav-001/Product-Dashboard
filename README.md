# 🚀 Product Dashboard

A modern and production-ready React Admin Dashboard built for managing products, analytics, users, and business operations with real API integration and scalable architecture.

Designed using **React 18, TypeScript, Redux Toolkit, RTK Query, TailwindCSS, and Vite**, this dashboard delivers high performance, clean UI, reusable components, and an optimized developer experience.

---

# ✨ Features

- 📦 Real API Integration  
- 🔍 Advanced Product Search & Filters  
- 📊 Analytics Dashboard  
- 🔐 Authentication & Protected Routes  
- 🎨 Dark & Light Theme Support  
- ⚡ Fast Performance with Vite  
- 🛠️ Redux Toolkit + RTK Query  
- 📱 Fully Responsive Design  
- 🧩 Reusable Components  
- ✅ TypeScript Support  

---

# 🛠️ Tech Stack

- React 18  
- TypeScript  
- Vite  
- TailwindCSS  
- Redux Toolkit

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/sumit-yadav-001/Product-Dashboard.git
```

## Navigate to Project

```bash
cd Product-Dashboard
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

---

# 🌐 Run Locally

```bash
http://localhost:3000
```

---

# 🚢 Production Build

```bash
npm run build
```
