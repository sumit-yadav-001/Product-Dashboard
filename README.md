🚀 Product Dashboard

A modern, scalable, and production-ready React Admin Dashboard designed for managing products, analytics, users, and business operations with real API integration and enterprise-level architecture.

Built using the latest frontend technologies like React 18, TypeScript, Redux Toolkit, RTK Query, TailwindCSS, and Vite, this dashboard provides high performance, clean UI, reusable components, and an optimized developer experience.
